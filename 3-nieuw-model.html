Een nieuw model in Workbench

Een model is een tekening van onze databank: tabellen, kolommen en relaties. Het staat los van de server. Pas in stap 6 zetten we het om naar een echte databank.

Met Forward Engineer maakt Workbench van het model een databank. Andersom kan ook: met Reverse Engineer maakt Workbench een model van een bestaande databank.

A. De verbinding controleren

  1. Start MySQL Workbench. Op het startscherm staat onder MySQL Connections een tegel, meestal Local instance MySQL80 of iets gelijkaardigs.

  2. Klik op de tegel en geef het wachtwoord in. Opent er een tabblad met links een Navigator? Dan werkt de verbinding. We mogen dit tabblad sluiten.

Geen verbinding?

Meldt Workbench dat het niet kan verbinden, dan draait de MySQL-server waarschijnlijk niet. Typ in Windows Windows + R, dan services.msc, zoek de service MySQL80 en kies Starten. Klopt het wachtwoord niet, vraag het dan aan je leraar.

B. Workbench instellen (één keer)

Workbench verzint zelf namen voor primaire en refererende sleutels. Standaard heet de PS van tabel artiest dan idartiest en de RS in een andere tabel artiest_idartiest. Met twee kleine instellingen volgen die namen onze afspraken: artiestID en artiestID.

  1. Kies in het menu Edit › Preferences…

  2. Kies links Modeling › Defaults.

  3. Vervang bij Column Defaults de waarde van PK Column Name door %table%ID.

  4. Vervang bij Foreign Key/Relationship Defaults de waarde van Column Name door %column%.

  5. Klik op OK.

Vergeten of op een andere computer?

Geen ramp. We kunnen elke kolom achteraf hernoemen in de tabeleditor. Het is wel sneller als Workbench meteen de goede naam voorstelt.

C. Een nieuw model aanmaken

  1. Kies File › New Model (Ctrl + N). Er opent een tabblad MySQL Model.

  2. Onder Physical Schemas staat al een schema met de naam mydb. Dubbelklik op het icoon van mydb. Onderaan opent de schema-editor.

  3. Typ bij Name: festival.

  4. Kies bij Charset/Collation de tekenset utf8mb4 en de sortering utf8mb4_0900_ai_ci. Zo kunnen we alle tekens bewaren, ook é, ë, ç en zelfs emoji.

  5. Bewaar het model: File › Save Model As… Kies je map Databeheer en de naam festival.mwb. Daarna bewaren we gewoon met Ctrl + S.

D. Een EER-diagram toevoegen

  1. Dubbelklik op Add Diagram bij EER Diagrams. Er opent een tabblad EER Diagram met een leeg tekenvlak.

  2. Bekijk het scherm. Links staat een verticale werkbalk met tekengereedschap, in het midden het tekenvlak en rechts de Catalog Tree met ons schema. Onderaan verschijnt straks de editor van wat we aanklikken.

  3. Beweeg met de muis over de knoppen van de werkbalk. Een tooltip toont de naam van elk gereedschap. Deze gebruiken we in de volgende stappen:

Gereedschap (tooltip)ToetsWaarvoor?
Place a New TableTEen tabel op het tekenvlak zetten

De werkbalk heeft ook identifying versies van de 1:1- en 1:n-relatie (toetsen 3 en 4) en een tool om een relatie te leggen met bestaande kolommen (6). Die hebben we voor ons voorbeeld niet nodig.

Bewaar vaak

Druk regelmatig op Ctrl + S. Workbench bewaart ook automatisch een reservekopie, maar ons eigen .mwb-bestand is wat we indienen en wat we mee naar huis nemen.
